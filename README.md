# raw-media-parser

`raw-media-parser` is an extraction and structuring pipeline that converts raw, non-text media (such as `.mp4`, `.mov`, and short-form video) into isolated visual and audio context that can be consumed by LLMs.

## What this project aims to do

- Ingest raw media files
- Separate useful visual and audio signals
- Structure extracted context into LLM-friendly outputs

## Supported media (initial scope)

- `.mp4`
- `.mov`
- short-form video content

This README is an initial project description and will evolve as implementation details, usage, and examples are added.
